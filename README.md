## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/sungbae-dev/clawed-workspace-sb.git
   cd clawed-workspace-sb
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:3000
   ```
